# ARCH APP 安全与可靠性审查修复

发布日期：2026-11-28
构建环境：Android SDK 34 / Java 17
签名证书 SHA-256：`f442665a4a9c89c36ba8027aaa85063e839932a2d5dd47e90d0d69c911d52a97`

## 本次修复

- 在线升级器：强制 HTTPS、受信发布域名、逐跳重定向校验、清单字段/大小校验、SHA-256 强制校验、包名/版本/正式签名校验；取消下载会中断连接且绝不进入安装。
- NRL 注册：删除明文 HTTP 回退，禁止跨协议重定向；限制执照照片和服务器响应大小，避免异常文件导致内存耗尽。
- PTT：悬浮 PTT 改为进程内直接投递；内部 PTT 广播在 Android 13+ 使用 NOT_EXPORTED，Android 7-12 使用签名级权限；Android 14+ 增加厂商广播发送 UID 校验。
- 音频：录音重启前同步停止并释放旧 AudioRecord；麦克风启动失败时立即撤销发射，避免界面显示“发射中”但实际无麦克风。
- 媒体服务：RadioPlaybackService 的 MediaSession 拒绝未受信任控制器。
- 网络安全：默认禁止明文流量，仅保留现有 FMO 端点和已知公开音频流域名白名单；禁用应用数据云备份和设备迁移。
- 兼容性：修正 PTT 映射对系统语言/区域设置的依赖；保留现有 DMR、数字中继、D-Star 声码器和音频编解码路径不变。

## 已知协议限制

FMO 的 HTTP/MQTT、NRL UDP 的密码字段、SIP UDP 以及旧 Android 厂商 PTT 广播属于服务端/厂商协议兼容问题。本次已限制客户端可达面和明文主机范围，但完整加密或挑战应答需要服务端或厂商侧配合；不能用客户端盲目改协议来破坏现有互通。
