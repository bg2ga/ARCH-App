# ARCH公开版 3.2.144 发布说明

版本：`3.2.144`

## 本版重点

- NRL 服务器目录改为双源自动更新：主接口 `nrlptt.com/api/platform-servers`，失败自动回退 `m.nrlptt.com/platform/list`。
- 目录本地缓存，15 分钟自动检查，失败 60 秒退避；空响应和网络失败不会清空可用服务器。
- 服务器选择器显示 `名称 · host:port · 在线数/总数`，当前服务器不会因目录暂时缺失而静默切回 ARCH。
- 切换服务器后自动连接并拉取频道，不再停在“已选服务器但无房间”的状态。
- 频道列表按服务器缓存；重新选择服务器时先显示缓存，再用服务器返回结果覆盖。
- 按服务器分别保存频道和服务器密码，避免切换服务器沿用上一台参数。
- NRL 软件设备身份对齐官方 Android 客户端：`SSID=107`、`DevModel=107`。
- 心跳固定 2 秒，连续 6 秒无服务器 NRL2 回包判定离线并自动重连，退避为 1/2/4/8/15 秒。
- 不再把 UDP socket 创建成功误报为“已连接”；只有收到服务器有效回包后才显示在线。
- 重做 NRL 连接区：服务器选择独占一行，刷新目录、添加服务器、注册服务器三个按钮等宽等高；小屏使用短标签。
- 频道区增加明确空状态和“刷新频道”入口。

## 验证

- 三种版本 Release 编译成功。
- APK 使用 ARCH 正式证书签名，证书 SHA-256：`f442665a4a9c89c36ba8027aaa85063e839932a2d5dd47e90d0d69c911d52a97`。
- 公网 NRL 服务器实测：收到服务器心跳确认在线，并成功解析 46 个频道。
- 服务器选择器与频道缓存回显已在模拟器验证。
- 未修改 DMR、数字中继、网络对讲、D-Star、SIP、APRS 的业务逻辑。
